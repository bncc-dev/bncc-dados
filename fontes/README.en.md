Provenance notes:

- The official export tool was down on 2026-07-09 (backend HTTP 503). The spreadsheets archived here were exported while the service was working.
- The Early Childhood Education (EI) spreadsheet is not available (the tool is down). The EI learning objectives are extracted directly from the homologated PDF.
- Be careful with versions: the PDF distributed on the Upper Secondary Education (Ensino Médio) page of the MEC website is the pre-approval draft (2018), with texts that differ from the final ones. Use only the complete homologated PDF.
- The Computing annex was obtained from the current CNE collection (`www.gov.br/mec/pt-br/cne/pdf/pareceres-do-cne/ceb/2022/`), which sits behind anti-bot protection (the download requires a browser; the hash above matches the server byte for byte). The legacy portal.mec.gov.br went offline in July 2026.
- The annex PDF has a non-standard xref table: poppler (`pdftotext`/`pdfinfo`) cannot read it directly. For extraction, normalize it first with Ghostscript (`gs -dNOPAUSE -dBATCH -sDEVICE=pdfwrite`). The file archived here is the untouched ORIGINAL; normalization is a pipeline step (`pipeline/anexo_computacao.py`), never a change to the source.
- Since 2026-10-14, the `computacao-estrutura.json` map replaces the support spreadsheets from the Pernambuco State Department of Education (Secretaria de Educação de Pernambuco) that used to be in `secedu-pernambuco/` (decision 13 in the decisions log, `DECISOES.md`, in Portuguese). The map stores the structure that the PDF text layer scrambles (axis, knowledge object, competency) and the text of each learning objective. Nothing in it is a source of truth: `pipeline/verificar_computacao.py` checks each text character by character against the official annex, which always prevails. Do not edit the map by hand; regenerate it with the script.

## Support spreadsheets that are not redistributed

The map was generated from these four files, which have **not been part of the repository** since 2026-10-14 (decision 13 in `DECISOES.md`). They are public training materials from the Pernambuco State Department of Education about the BNCC Computing supplement, obtained by the team on 2026-07-11, with no explicit redistribution license. They are recorded here by name and SHA-256 for traceability.

- To regenerate the map, put the four files in a directory and run `python3 pipeline/gerar_mapa_computacao.py /caminho/do/diretorio`. The script checks the SHA-256 hashes above before reading and reproduces the map byte for byte.
- The "Habilidade(s) do Currículo de Pernambuco" (Pernambuco Curriculum skills) column of these spreadsheets never entered the dataset or the map.
- **Authorship metadata removed** from `6º ao 9º ANO - HABILIDADES - BNCC - Computação .xlsx` on 2026-07-27: the `dc:creator` property of the OOXML package contained the name of a private individual. Only that field was removed. That is why the SHA-256 recorded for this file does not match the hash of the original file received.
- **Exact origin**: these spreadsheets have no documented source URL, only the date they were obtained. *(open issue)*
- Until 2026-10-14, the files were redistributed in this directory, with attribution to the Department. They remain in the git history and in the versions already published on Zenodo. Contact for any request from the Department: contato@bncc.dev.
