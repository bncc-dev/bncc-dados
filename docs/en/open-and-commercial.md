# Open/commercial split · public commitment

Recorded since the first commit, as set out in the project plan.

| Layer | Status | License |
|---|---|---|
| Data (JSON and derived files) | **Irrevocably open**, no sign-up, no API key | CC BY 4.0 |
| npm/PyPI packages (future) | **Irrevocably open** | MIT |
| Local MCP server (future) | **Irrevocably open** | MIT |
| Templates and examples (future) | Open | MIT |
| Lookup website (future) | Open, no sign-up | · |
| Hosted API, SLA, support (future) | Commercial (freemium with a generous free tier) | · |
| Custom integrations / consulting | Commercial | · |

**Golden rule: nothing moves from the open column to the commercial one. Ever.** The reverse path is always allowed.

Monetization, if any, stays in convenience services on top of the foundation, never in access to the data.
